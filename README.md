# 悪役結界貴族もの（仮題）

日本人の魂を吸収した悪役貴族が、血統魔法《障壁》を《結界術》へ発展させ、原作ゲームの運命と世界の常識を覆す異世界ファンタジー。カクヨム連載予定。

非公開の執筆用リポジトリです。AIと共同で執筆します。AIへの案内は `AGENTS.md` にあります。

## フォルダ構成

```
AGENTS.md            AIが最初に読む案内（CLAUDE.md はこれを読み込むだけ）
progress.md          進み具合・次の予定・設定の変更履歴

planning/
  brief-v0.1.md      作者の企画書（原文）
  concept.md         作品の狙い・守る方針
  story-outline.md   構成と構想（第一部の山場など）
  open-questions.md  未確定事項と、作者に判断してもらうこと

setting/
  world.md               世界・称号・血統魔法・魔力
  barrier-and-kekkai.md  《障壁》と《結界術》、開発ログ
  original-game.md       原作ゲーム・原作主人公・ラスボス

characters/
  protagonist.md     主人公
  supporting-cast.md 脇役

writing/
  style-guide.md     文体と表記のルール（前作から引き継ぎ）
  drafts/            本文の下書き（1話1ファイル）

tools/
  novel-studio.html  執筆スタジオ（前作と同じもの）
```

## 執筆スタジオ（編集ツール）

`tools/novel-studio.html` を Chrome か Edge で開き、このフォルダを選ぶと使えます。使い方は前作と同じです。

- 左の「話」で各話、「資料」で設定ファイルを開く。
- 編集すると、右のカクヨム式プレビューにすぐ反映される。ルビ（`|親文字《るび》`）と傍点（`《《強調》》`）にも対応。
- サブタイトルとステータス（下書き／手直し済み／公開済み）は上の欄で変える。手直しした話は「手直し済み」にしておくと、AIがその本文を勝手に直さない。
- 保存は Ctrl+S。GitHubへの反映は、コミットとプッシュで行う。

## 設定のラベル

【確定】作者が明言した ／ 【仮案】作者が検討中 ／ 【AI案】AIの提案（未承認） ／ 【未定】
